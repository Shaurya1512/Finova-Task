# Finova-Task
Quantitative Finance Task

Reliance had two trades in the last 12 months, both of them lost money, one lost around 0.5%, whereas the other lost around 5.4%, giving a 0% win rate. EMA crossovers lag behind because they only confirm when the price has actually moved. For example in the second trade, the stock went up a lot after I entered, but the exit signal only came after the price had already fallen back down below where I entered, so I ended up missing the whole upward move and still took a loss on the way down. This strategy would probably work better in a slow, steady trend that moves in one direction for a long time, because the lag matters less there. But it does badly in sharp ups and downs like this one, because both the entry and the exit come too late. Based on these two trades, I would not trade this strategy with my own money, at least not on its own. Two trades is not a lot to go on, but both losses happened for the same reason, the lag. The strategy needs something extra added to it before I would trust it.
